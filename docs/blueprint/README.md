# Blueprint — Requirements Baseline

`Aziv_AI_FINAL_Master_Blueprint.pdf` is the master software specification supplied by the project
owner (8 pages, revision 11 September 2026). `.txt` is a plain-text extraction for searching and
diffing.

Per **Rule 2** of the blueprint, this document is the requirements baseline. **Features must not
be removed from it without the owner's explicit approval.** Every section is tracked in
`../01-requirements-register.md`; any scope change requires a row edit there and the owner's
sign-off.
